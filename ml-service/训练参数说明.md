# Stage A Applicability模型训练参数说明

## 命令行参数

### 基本参数

- `--model`: 模型类型
  - 可选值: `lr` (LogisticRegression), `xgb` (XGBoost), `rf` (RandomForest)
  - 默认值: `xgb`

- `--model-version`: 模型版本号
  - 默认值: `002_aug`
  - 示例: `002_aug`, `003_custom`

### 采样参数

- `--max-pos`: 正类（CVE）最大采样数
  - 默认值: `80000`
  - 说明: 从 `merged_json_table.csv` 中采样的CVE描述数量
  - 示例: `--max-pos 50000`

- `--max-neg`: GitHub负类最大采样数
  - 默认值: `10000`
  - 说明: 从 `negative_github_issues.csv` 中采样的GitHub issues/PRs数量
  - 示例: `--max-neg 8000`

- `--max-aug-neg`: 增强负类最大采样数
  - 默认值: `None` (不限制)
  - 说明: 从三个增强负类数据集（noise, keyword_only, patch_mitigation）中采样的总数量
  - 示例: `--max-aug-neg 5000`

- `--target-neg-ratio`: 目标负类:正类比例
  - 默认值: `1.75` (即1.75:1)
  - 说明: 如果总负类数量超过 `正类数 * target_neg_ratio`，会进行下采样
  - 示例: `--target-neg-ratio 2.0` (2:1比例)

### 其他参数

- `--use-aug-negatives`: 使用增强负类数据（默认启用）
- `--no-aug-negatives`: 不使用增强负类数据

## 使用示例

### 1. 使用默认参数训练XGBoost模型

```bash
python ml-service/train_applicability_model.py --model xgb
```

### 2. 自定义正负样本数量

```bash
# 正类50000，GitHub负类8000，增强负类不限制
python ml-service/train_applicability_model.py --model xgb --max-pos 50000 --max-neg 8000
```

### 3. 限制增强负类数量

```bash
# 增强负类最多采样5000条
python ml-service/train_applicability_model.py --model xgb --max-aug-neg 5000
```

### 4. 调整负类:正类比例

```bash
# 目标比例2:1
python ml-service/train_applicability_model.py --model xgb --target-neg-ratio 2.0
```

### 5. 完整自定义示例

```bash
# 正类60000，GitHub负类10000，增强负类4000，比例1.5:1
python ml-service/train_applicability_model.py \
    --model rf \
    --max-pos 60000 \
    --max-neg 10000 \
    --max-aug-neg 4000 \
    --target-neg-ratio 1.5 \
    --model-version 002_custom
```

### 6. 不使用增强负类（仅使用原始GitHub负类）

```bash
python ml-service/train_applicability_model.py --model xgb --no-aug-negatives
```

## 采样逻辑说明

1. **正类采样**: 从CVE数据中随机采样 `max_pos` 条（如果数据不足则全量）

2. **GitHub负类采样**: 从GitHub issues中随机采样 `max_neg` 条（如果数据不足则全量）

3. **增强负类采样**:
   - 如果指定了 `max_aug_neg`，按子类分层采样，总数量不超过 `max_aug_neg`
   - 如果未指定，使用全部增强负类数据

4. **最终负类采样**:
   - 合并GitHub负类和增强负类
   - 如果总负类数量 > `正类数 * target_neg_ratio`，进行下采样
   - 下采样时优先保留GitHub负类，对增强负类进行分层采样

## 数据统计

训练完成后，数据集组成统计会保存到：
- `models/app_model_{version}_{model}/dataset_stats.json`

包含：
- 总样本数
- 正类/负类数量
- 负类:正类比例
- 各子类分布（github, noise, keyword_only, patch_mitigation）
